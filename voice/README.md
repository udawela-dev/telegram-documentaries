# voice/

Archive folder for narrator voice assets and — in time — generated voice notes.

Contents:
- `chirp3-hd-achird.wav` — Chirp 3 HD voice sample (the "Achird" voice profile
  used by the Narrator's TTS pipeline).

The bot currently delivers voice notes straight to the Telegram chat via the
Narrator (Phase 6). Wiring the Narrator to also write archived `.ogg` copies
into this folder is an optional follow-up feature (requires a spec and a PR —
ask the build agent).
